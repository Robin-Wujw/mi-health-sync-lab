# 日常使用

手机已安装 healthlab.22，日常同步不需要电脑或 ADB，也不需要运行测试 APK。

- 保持 Zepp 向 Health Connect 写入数据。Mi Health Sync Lab 的自动同步、所需后台读取及系统自启动已经开启。
- 系统会择机运行后台同步，当前后台范围为最近 1 天。需要补更早历史时，在手机 App 中选择更大范围并同步。
- 新 GPS 轨迹若要求单独授权，在 App 的“授权 GPS 轨迹”中处理；已授权的轨迹可在后续同步中使用。
- “运动 → 小米”是运动导入，“最大摄氧量 → 小米”是 VO₂max 导入。此前摄氧量误显示成第二个“运动”的问题已修复。

PAI、活力、训练负荷、训练效果及恢复时间目前不导入；速度、配速、步频和功率曲线尚未导入。已验证的数据项与限制见验收清单。

用户已决定两条早期测试记录的旧缓存暂不处理；这些记录可能仍显示小米的旧本地缓存。云端文件已经修正；处理该私有缓存可能影响登录、本地设置和未同步数据，因此没有自动清除小米应用数据。

如需重新安装，使用主 APK 覆盖安装即可保留本应用设置与同步账本；测试 APK 仅供开发验证。不要为了重试而清除本应用数据，否则会丢失防重复与不确定写入的账本。

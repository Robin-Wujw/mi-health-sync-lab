# 同步任务改造状态

本轮基于修改规格和交付包推进 Android 实现；原型不作为设备验收证据。

| 领域 | 已实现 | 剩余验收或工作 |
| --- | --- | --- |
| 手动同步 | 同步页范围下拉；请求冻结绝对范围、指标、账户代次、Zepp 来源指纹和来源时区；连续替换保留最新候选，独立停止取消候选；首页有任务时只打开详情；运行卡显示任务来源和起止时间。旧格式的 Zepp 云端任务不猜测来源，要求重新提交 | 连续点击、权限弹窗、无障碍和任务进度切换需要设备验收 |
| Android Service | 派发前持久化请求，Intent 只传 runId；重投递恢复原窗口、指标及账户代次；终态和正在停止的旧任务不重跑；未完成预检或派发的替换须确认或取消；最近 20 条脱敏摘要外，单独保存上次自动跳过的原因；新进程将未结案的旧自动任务归档为中断 | 分片级历史待补；需真机核对锁屏、划掉最近任务、系统回收及强行停止 |
| 自动同步 | 自动/手动范围分离；按原分片续跑，长期缺口轮转；小米普通、医疗按时间读取和运动索引可从原任务的游标页恢复；继续取得新页时不把预算耗尽视为无进展。Zepp 满页保存逻辑子窗口 | 运动索引只保存解析后的摘要；FDS 详情和导入写入回读不使用读页缓存。Zepp 压力子窗口重读必要上下文；iOS 需 Xcode 和设备验收 |
| 来源日报 | 显式设置 Zepp 来源时区后，自动同步安排已结束、原始水位已覆盖的完整来源日；日报有独立时间预算与验证水位。心率、睡眠、血氧全片读取后才聚合；23/25 小时日按实际午夜边界处理，偏移不符或分片缺失不报成功 | 跨偏移的单条记录仍保守处理；既有日报继续保留，不做修订；需测试账号/真机回读验证 |
| Android 写入 | 读取目标失败不覆盖；路线与 notes 独立防降级；路线点采用 `[start, end)`；累计量按已存运动子记录扣除 | 需真机核对跨日、历史权限、不同账号及提供方读取语义 |
| 账号与云端 | 登录和注销更新持久账号代次；旧刷新写回被拒绝；注销等待活动同步退出；体重未知写入不重放，明确 429 有退避上限；Zepp 满页有界拆窗 | 只用假服务离线验证；日报迟到更新及真实回读仍待验证 |
| GPS 缓存 | 排除备份和设备迁移；旧格式无授权时间时清理；按账号代次隔离、24 小时有效期、注销和检测到权限撤销时清除；CI 静态门禁校验 preferences、云备份和 D2D 排除 | Android 真机备份、设备迁移及撤权流程待验收 |
| Apple Health | 运动失败按实际结果报告，提交状态未知时不尝试备用写入；皮温不写成体温；I02 改为按本 App 来源和稳定 ID 读取既有版本，内容不变时跳过，变化时在原版本上递增并回读核对 | 尚未用 Xcode 构建；真机待核对高位 NSNumber 精度、只读本 App 数据、重装后查询、关联运动样本及血压关联数据更新 |
| 发布 | 沿用现有 `.40` 下载；新 Release 无签名凭据会被阻断；重复及降级 Android 版本会被拒绝；shell 门禁统一 LF 并已在 WSL 验证；仅匹配经 iOS 设备验收的提交才附带 IPA | 正式签名迁移、设备矩阵、GitHub CI 实跑及 iOS 最终验收未完成 |

| D05–D06、D08 | 本地版本、阻断和测试脚本通过；还需验证远端失败测试真能阻止发布、配置受保护签名并核对迁移。 |
| D07 | 旧格式、过期、换号及撤权的主机回归已跑；真机备份和迁移尚未验证。 |
| D09 | 体重 429、未知结果及受限恢复有离线回归；仍需受控账号回读和延迟验证。 |
| D11 | Zepp 事件按显式续页信号或满页有界拆窗；自动模式保存固定半开子窗口和已知存在的流，不保存源数据。全天压力超过自动探测预算时拆分逻辑窗口；每片保留两侧上下文，若最小片仍饱和或上下文缺失，则不输出部分压力时间线。子窗口 404 不当成无数据，只核验完成的子窗口推进水位。真实账号页序、压力事件跨度、延迟和预算仍需核对。 |

逐例的证据层级及待验清单见 `SPEC-ACCEPTANCE-MATRIX.zh-CN.md`。

小米分页临时缓存与任务历史分开。每个文件只在游标和前序页一起原子写入后可恢复，以任务/计划、账号代次、源账号、区域、端点和固定时间窗隔离；仅当下次请求得到服务端响应，才把前序页与后续页合并。拒绝旧游标时丢弃该前缀并从原窗起点重读。Android 放在 `noBackupFilesDir`，iOS 使用缓存目录（不可用时用临时目录）；使用期 3 小时，单项 2 MiB、总量 24 MiB，任务结束、明确停止、注销或换号时清理。不会把游标或健康原始页纳入历史和诊断；iOS 编译、真机存储与迁移行为尚未验证。

运动索引另按防回环账本快照隔离。已核验的自有运动和删除记录先排除，再保存解析后的源摘要；不保存 GPS 坐标、原始运动响应或 FDS 文件。写入验收、冲突识别和未知写入恢复继续从服务端重新读取，不由缓存证明写入成功。

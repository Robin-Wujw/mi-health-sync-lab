# HealthLab .36：睡眠明细来源修正

版本：1.0.6-healthlab.36（1000042），2026-11-12。

本轮 ADB 发现手机原先安装 .34。覆盖安装 .35 后确认来源中有睡眠心率、血氧与夜间呼吸数据，但睡眠明细文件接口拒绝 default 来源，业务码 -6，属于设备不存在。摘要可保存的来源并不自动具备 FDS 文件能力。

## 修复

普通睡眠与 HRV 导入改用小米文件接口认可的应用来源 xiaomiwear_app_manually，摘要与明细保持同一来源。其他指标以及日汇总身份保持原有规则。

旧 default 导入睡眠自动迁移：核对本软件拥有的精确旧内容、排除 pending 写入、在应用私有存储保存原摘要、上传并独立逐字节核对明细、通过普通 runner 写入并读回新摘要，最后才退休旧占位并再次读回。旧归档和历史账本保留。未知删除只读回核对，不以更换身份为由重发；云端条目发生变化或并非本软件拥有时停止迁移。

后续来源修订使用新文件引用，保留 HRV 与云端扩展。没有增加按钮、工具入口或开关。

## 仍未支持

HRV 个人基准尚未支持。当前手机小米 3.61.0 的有效日计数要求原生 HRV 分析标记，显示区间还要求基准上下限；当前 mapper 只同步 HRV 汇总值。已有七天睡眠不能直接满足这些条件。详情见 HRV-BASELINE-2026-11-12.zh-CN.md。

睡眠效率来源未提供，未造值。单独的后台调度、跨多日登录保持、压力 pending 与其他历史待办并未因此宣称验收完成。没有构建 iOS。
